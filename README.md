# 🚦 DetectaVial Ecuador

Sistema inteligente de detección y verificación de señales de tránsito basado en **Yolov8** y adaptado a la normativa oficial del **MTOP / INEN (Ecuador)**.

## 🚀 Características
- **Interfaz iOS 18 Glassmorphism:** Diseño moderno, limpio y minimalista.
- **Cálculo de Distancia:** Estimación en tiempo real de la distancia en metros hacia la señal detectada.
- **Registro Automático:** Almacenamiento automático en CSV de aquellas señales no mapeadas para su posterior incorporación al diccionario.
- **Actualización Dinámica:** Conectado directamente para reflejar cambios al instante.

## 🛠️ Tecnologías
- Python & Streamlit
- Ultralytics YOLOv8
- OpenCV & Pillow
